The type system

Made to make a mark.

This page provides a direct download for CTG Signature Script, an original display font built for both desktop and web use. The package is made for energetic brand moodboards, posters, social graphics, website accents, quote cards, and presentation headers.

The font package includes desktop install formats for creative apps and a compressed WOFF2 file for website embedding. If you want to preview the font before downloading, you can view the specimen page or inspect the preview images below.

Embed on a Website 
@font-face {
  font-family: "CTG Signature Script";
  src: url("/assets/fonts/ctg-signature-script/CTGSignatureScript.woff2") format("woff2");
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}

.signature-text {
  font-family: "CTG Signature Script", cursive;
}

Character Coverage

CTG Signature Script includes uppercase and lowercase Latin letters, numerals, core punctuation, plus additional web-friendly glyphs including an ampersand, brackets, copyright, registered trademark, degree symbol, en dash, and em dash.

License and Distribution

The font is distributed by Cursive Text Generator under the SIL Open Font License 1.1. That makes it easy to share, bundle, and use in personal or commercial design workflows while keeping the original font software under a clear open font license.

Rebuild Notes

The original scripted glyph source and reproducible build pipeline are kept in this repository. The source recipes live in font-source/ctg_signature_script/source.py and the build command is ./.venv/bin/python scripts/build-font.py.
