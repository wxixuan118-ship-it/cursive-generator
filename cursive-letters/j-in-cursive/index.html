How to Write J in Cursive

Uppercase J

Uppercase cursive J drops well below the baseline into a descender loop, then swings back up. It is one of the few capitals that crosses the baseline.

Lowercase j

Lowercase j is a short downstroke that curves left below the baseline, plus a dot placed above the x-height after the stroke is finished.

Cursive j vs Cursive i

In cursive both carry a dot. The j descends below the baseline with a loop; the i stops at the baseline.

Cursive J FAQ

How do you write J in cursive?

Uppercase cursive J drops well below the baseline into a descender loop, then swings back up. It is one of the few capitals that crosses the baseline. Lowercase j is a short downstroke that curves left below the baseline, plus a dot placed above the x-height after the stroke is finished.

What is the difference between cursive j and cursive i?

In cursive both carry a dot. The j descends below the baseline with a loop; the i stops at the baseline.

Can I copy and paste J in cursive?

Yes. Every J on this page is a Unicode character, not an image, so clicking it copies real text. Paste it into an Instagram bio, a TikTok display name, a Discord nickname, or a document and the cursive shape travels with it — no font to install.

Why does cursive J look different in each style?

Each row uses a different Unicode block. Cursive Script and Bold Cursive come from the Mathematical Script ranges, Old Style Script from Fraktur, and Double-Struck and Clean Fancy from their own blocks. They are separate character sets that happen to resemble handwriting, which is why the same letter is drawn differently in each.

Is the cursive J here a real handwriting font?

No. These are Unicode characters, not a downloadable typeface. That is why they work in fields that never let you change the font. If you need an actual font file for print or design software, see our cursive fonts page.
