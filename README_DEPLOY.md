# Cursive Studio Deployment

This folder is a static Vercel-ready website for:

- `cursive font generator`
- `cursive text generator`

## Deploy to Vercel

1. Go to https://vercel.com/new
2. Choose **folder** upload.
3. Upload this folder: `cursive-site`
4. Deploy.

## Production Domain

The SEO metadata, canonical URLs, Open Graph image URLs, robots file, and sitemap are already configured for:

```text
https://cursive-text-generator.net
```

## Files

- `index.html` targets `cursive font generator`
- `cursive-text-generator.html` targets `cursive text generator`
- `assets/app.js` powers the text generator
- `assets/styles.css` contains the site styles
- `assets/cursive-generator-hero.png` is the hero image
- `vercel.json` contains static deployment settings
