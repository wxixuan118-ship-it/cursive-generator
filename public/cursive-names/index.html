Names in Cursive — How It Works

Every name on this site is shown in Unicode mathematical script characters — the digital equivalent of handwritten cursive. Because these are standard text characters, not images or font files, you can copy them and paste them directly into Instagram display names, TikTok bios, Discord nicknames, WhatsApp, iMessage, and most other apps.

15 Styles per Name

Each name page shows the name in all five Unicode script alphabets (script, bold script, gothic, double-struck, monospace) in three cases (title case, ALL CAPS, lowercase) — 15 variants total. Each page also includes signature styles, tattoo references, Instagram username ideas, and similar name suggestions.
