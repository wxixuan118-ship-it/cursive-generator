    How to Make a Good Summoner Name

    The generator follows a handful of formulas you will recognise from any champ select. Knowing them helps you tweak a result or build your own summoner name by hand.

    Champion + main / OTPYasuo + Main, Ahri + OTP → the League classic; says who you play
    Role + diff / gapMid + Diff, Top + Gap → the taunt format; funniest when you are the one who lost lane
    Sweaty adjective + nameCracked / Clutch + Kai → says how you play before your name lands
    Region + lore nounNoxian + Vanguard, Ionian + Sentinel → Runeterra in one word
    Rank joke + nounIron / Bronze + Inter / Feeder → self-deprecating ARAM names
    Name + space + wordKai + Main with a space → Riot IDs allow spaces; most other platforms do not
    Duo pairKai + One / Two → matching names for a botlane duo; swap the suffix
    Name + #taglineKai + #OTP → the tagline is where a joke or a region goes

    One trick per name, and put the joke in the tagline. YasuoMain#OTP is a summoner name; xX_Y4su0_M41n_Xx#1337 is not, and Riot would reject the underscores anyway. Riot only lets you change the ID every 30 days, so generate a few before you commit.

    How Our Summoner Name Generator Works

    There is no AI behind this page and no connection to Riot Games. Summoner names are assembled in your browser from five ingredients:

    • Your word. The name or word you type is cleaned to letters and numbers and kept whole in every result. Leave it blank and the generator picks a League noun instead.
    • League vocabulary. Each of the eight styles has its own hand-written list — Yasuo, Ahri and Jinx with main/OTP for champions; mid, top and diff for roles; Noxian, Ionian and Darkin for lore — so a funny result never borrows a sweaty word by accident.
    • Champ-select patterns. Champion + main, role + diff, adjective + name, region + lore noun, rank jokes, spaced two-word names, duo suffixes and tagline pairing. Patterns rotate within a batch so you never get 24 versions of the same idea.
    • Riot-safe defaults. Symbols off, Mixed case on and a hard 16-character cap, so every result fits the Riot ID field as written.
    • Favorites. The heart saves a name to your browser's localStorage. Nothing is sent to a server, and the generator cannot check whether a Riot ID + tagline is free — the Riot account page checks as you type.

    Summoner Name Rules — From Summoner Names to Riot IDs

    League of Legends retired the old summoner name system in late 2023: your in-game name is now a Riot ID — a name of 3 to 16 characters (letters, numbers and spaces, no symbols) plus a #tagline of 3 to 5 characters — and it is shared across League, TFT, Wild Rift and Valorant. The combination has to be unique, not the name alone, so Kai#OTP and Kai#EUW can both exist, which makes good names far easier to get than they were when summoner names were unique per region. You change it from account.riotgames.com → Riot ID once every 30 days.

    People still search for a summoner name generator because the term stuck, and the formats did too: champion + main, role + diff, region + lore noun. This page keeps those formats, caps the name at 16 characters and offers a Short preset for names that leave room for a meaningful tagline. The Valorant name generator uses the same Riot ID rules with agent vocabulary; for a name that also fits a console, the gamertag generator keeps it under Xbox's 12 characters; the Discord username generator handles the lowercase handle for your team's server; and the main username generator mixes every style in one tool.

    The switch from summoner names to Riot IDs and the character rules are documented in Riot's support article on Riot IDs in League.

    Summoner Name Generator FAQ

    What is a summoner name generator?

    It is a tool that combines a word you choose with curated League of Legends vocabulary — champions, roles, lore regions, sweaty terms, rank jokes — and champ-select naming patterns to produce Riot IDs that fit the 3–16 character rule. This one runs in your browser, is free, and lets you copy any result with one click.

    What are some good summoner name ideas?

    Examples from the styles above: YasuoMain, MidDiff, CrackedPenta, IronInter, NoxianVanguard, FrostVortex, TwinBotlane and lunahaze. Type your own name to get versions built around it, such as CrackedKai or KaiMain, then add a tagline like #OTP.

    Are summoner names still a thing in League of Legends?

    Not as a separate system. Since late 2023 League uses Riot IDs — name plus #tagline — shared with Valorant, TFT and Wild Rift. People still call them summoner names, and the formats (champion + main, role + diff) carried over, which is what this generator produces.

    How many characters can a League of Legends name have?

    The Riot ID name is 3–16 characters of letters, numbers and spaces; the tagline after the # is 3–5 letters or numbers. No symbols, underscores or periods in either. This generator caps every result at 16 characters so it fits as written.

    How do I change my summoner name?

    Sign in at account.riotgames.com, open Riot ID and edit the name and tagline. Riot allows one change every 30 days, and the change applies to League, TFT, Wild Rift and Valorant at once. The page shows immediately whether the combination is available.

    Does this summoner name generator check availability?

    No. Nothing here talks to Riot, so it cannot know whether a Riot ID + tagline is taken. Because the tagline makes the combination unique, most names are available with some tagline — copy the one you like and try it on the Riot account page.

    What is a good League of Legends tagline?

    A region (#EUW, #NA1, #KR), a role or champion joke (#OTP, #DIFF, #GAP, #MID) or a number that means something. Keep the joke in the tagline and the name clean, so the name still works if you change the tagline later.

    Can I copy and paste the generated summoner names?

    Yes. Every result has a Copy button, Copy All Usernames copies the visible list one per line, and the heart saves a name to My Favorites in your browser. Paste the name into the Riot ID field and choose your tagline there.
