What Is a Gothic Font Generator?

A gothic font generator converts plain text into Unicode characters that resemble Gothic script — also known as blackletter, Fraktur, or Old English script. Gothic script was the dominant writing style in Western Europe from the 12th to 17th centuries, characterised by angular, dense, dramatic letterforms with strong vertical strokes and decorative serifs.

This generator produces Gothic-style text using the Unicode Fraktur block, which contains characters designed to replicate blackletter letterforms. The result — 𝔊𝔬𝔱𝔥𝔦𝔠 — can be copied and pasted into any app or platform that supports Unicode text.

Gothic Font vs Old English Font

Gothic font and Old English font refer to overlapping but slightly different traditions. Old English script refers specifically to the insular script used in Anglo-Saxon manuscripts before the Norman Conquest. Gothic script (blackletter/Fraktur) developed later, between the 12th and 17th centuries, and is the style most people picture when they think of 'gothic letters'.

In everyday usage — and in font naming conventions — the terms are often used interchangeably. This generator's Old Style Script style covers both aesthetics. For a dedicated Old English page, see our Old English Font Generator.
