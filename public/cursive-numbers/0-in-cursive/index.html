How to Write 0 (Zero) in Cursive

Draw a narrow oval beginning at the upper-left (11 o'clock). Sweep counterclockwise — curve up and right across the top, down the right side, left along the bottom, and close the loop where you started. The oval leans slightly to the right, about 10–15° from vertical.

Stroke Steps

  1. Place pen at 11 o'clock on the oval's rim
  2. Curve counterclockwise up and to the right
  3. Sweep down the right side
  4. Continue left along the bottom and close the loop at the start

0 in Print vs Cursive

Zero looks nearly identical in both forms — both are ovals. The cursive version has a subtle rightward lean and a more fluid, continuous stroke. Of all ten digits, zero changes the least between print and cursive.

Common Uses of 0

The number 0 (zeroth) appears frequently in: 10, 100, 1,000, percentage, phone number. Typing any of these into the generator above shows how 0 integrates naturally into cursive text.

FAQ — 0 in Cursive

How do you write 0 in cursive?

Write a narrow, slightly-right-leaning oval in a single counterclockwise stroke. Start at the upper-left, sweep across the top, down the right, along the bottom, and close where you began. No pen lifts required.

Is 0 hard to write in cursive?

No — zero is considered the easiest cursive digit. It is a single continuous oval stroke with no sharp angles, crossings, or pen lifts.

Does 0 look different in cursive vs print?

Barely. Both are ovals, but the cursive zero leans slightly to the right and has smoother entry and exit strokes. It is the digit that changes least from print to cursive.

Can I type 0 in different cursive styles?

Yes. Use the generator above — type '10' or '100' to see zero alongside cursive letters in each style. Numbers render as regular digits in cursive-adjacent Unicode blocks.
